# TrustID Backend

Prototype backend for the TrustID competition project.

## Stack

- Node.js
- Express
- MongoDB + Mongoose
- JWT authentication
- bcrypt password hashing
- Helmet, CORS and rate limiting

## 1. Install

```bash
npm install
```

## 2. Environment

Copy `.env.example` to `.env` and fill in:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=your_mongodb_atlas_connection_string
JWT_SECRET=your_long_random_secret
CLIENT_URL=http://localhost:3000
```

## 3. Run

```bash
npm run dev
```

Health check:

`GET http://localhost:5000/api/health`

## Prototype flow

1. Register
2. Login
3. Save onboarding
4. Grant consent
5. Submit simulated financial behaviour
6. Generate Trust Profile
7. Read score, factors, insights and recommendations
8. Ecobank officer/admin can view customer decision-support data

## TrustID scoring

Total = 850 points:

- Income Consistency: 200
- Savings Behaviour: 150
- Repayment Behaviour: 200
- Cash-flow Stability: 150
- Financial Discipline: 150

This is a competition prototype scoring model, not a production credit-risk model.

## Demo financial profile example

Use this payload for `POST /api/financial-profile` after consent:

```json
{
  "incomeConsistency": 82,
  "savingsRate": 76,
  "savingsStreakMonths": 8,
  "repaymentOnTimeRate": 97,
  "missedPayments": 0,
  "cashFlowStability": 71,
  "lowBalanceDays": 4,
  "budgetingDiscipline": 79,
  "recurringPaymentConsistency": 88,
  "averageMonthlyInflow": 450000,
  "averageMonthlySavings": 90000,
  "monthlyExpenses": 280000
}
```

Then call:

`POST /api/trust-profile/generate`

The score is generated by `src/scoring/scoreEngine.js`.
